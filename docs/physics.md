# Physics Background

## Borosilicate Glass Dissolution

1. **Stage I** - Initial fast dissolution (far from saturation)
2. **Stage II** - Residual rate limited by gel layer diffusion
3. **Stage III** - Rate resumption due to secondary phase precipitation

## TST Rate Law

    r = k0 * exp(-Ea/RT) * a(H+)^n * (1 - exp(-A/RT))^eta

See nuclear_glass.physics.thermodynamics for implementation.
